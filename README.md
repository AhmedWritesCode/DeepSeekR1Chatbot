# 🍓 Strawberry Magic Chatbot

**API Service:** [OpenRouter](https://openrouter.ai/settings/keys)  
**Live Demo:** [https://ahmedwritescode.github.io/DeepSeekR1Chatbot/](https://ahmedwritescode.github.io/DeepSeekR1Chatbot/)

Strawberry Magic Chatbot is a web-based AI assistant with a friendly pink theme.  
It supports **text chat** and **image uploads** for analysis, returning AI-generated responses in Markdown format.

---

## How It Works
1. User enters a message or uploads an image.
2. The chatbot sends the input to the [OpenRouter API](https://openrouter.ai/) with the chosen AI model.
3. AI processes the text/image and returns a response.
4. Response is displayed in the chat UI with Markdown formatting.

---

## Features
- 💬 Text-based chatbot with conversation history during session.
- 🖼️ Image upload and AI vision analysis.
- 🎨 Responsive pink strawberry-themed design.
- 📝 Markdown rendering for formatted AI responses.

---

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Styling:** Bootstrap, Google Fonts
- **Markdown Parser:** marked.js
- **AI API:** OpenRouter (Text + Vision models)

---

## Quick Start
> This method exposes your API key in client code. Use only for testing.

1. Download or clone the repository.
2. Open `index.html` and replace the API key with your [OpenRouter API Key](https://openrouter.ai/settings/keys).
3. Open `index.html` in a browser.
